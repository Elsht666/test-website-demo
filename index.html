无法下载？
  • 官网「latest」跳转链接（如 central.github.com/.../latest/win32）不是直链：粘贴后点「提取」会自动解析成最新版本直链，再复制加速链接即可
  • 卡在最后一点一直没完成：多半是连接被掐断，换 Chrome / Edge / Firefox 等浏览器重试
  • 也可以点「测速」，把通道切到更快的可用通路再试
  • 想要更高速率：多数加速站的高速节点需注册并购买 VIP / 会员，免费公益通道通常限速、不稳定
  • 如果你有自己搭的或买的通路：选「自定义前缀」通道，在下方输入你的加速地址即可
  • Xget 通道对 GitHub / GitLab / HuggingFace 生效，其他站点会自动改用通用前缀通道
